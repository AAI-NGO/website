# Ancient-Advanced India — WebsiteThis is the full source for the AAI website, ready to host on **GitHub Pages**.## 1\. Deploying it1. Create a new GitHub repository (e.g. `ancient-advanced-india`).2. Upload everything in this folder to that repository (drag-and-drop on github.com works fine, or `git push`).3. Go to **Settings → Pages** in the repo, set **Source** to the `main` branch, root folder.4. Your site goes live at `https://<your-username>.github.io/<repo-name>/` within a minute or two.No build step, no server, no environment variables. It's plain HTML/CSS/JS.## 2\. Adding a new file to the Resource Library (the "upload" feature)Because GitHub Pages can't run a real upload server, the library works a different way: **your GitHub write access is the admin permission.** Only people who can push to this repo can add files — visitors can only view and download.To publish a new workshop kit or event photo:1. **Add the file** to either:   * `workshop-materials/` — kits, templates, reports   * `media-gallery/` — photos, videos2. **Open `data/files-manifest.json`** and add one entry for it, for example:```json   {     "name": "Agricultural Innovation Workshop Kit.pdf",     "path": "workshop-materials/agri-innovation-kit.pdf",     "date": "2026-08-02",     "size": "1.1 MB",     "type": "pdf"   }   ```* `name` — what visitors see* `path` — the file's location relative to the site root (must match exactly where you put the file)* `date` — `YYYY-MM-DD`, used to decide what counts as "latest"* `size` — shown as a label only, doesn't need to be exact* `type` — `pdf`, `image`, `video`, or `doc` (controls the icon shown)3. **Commit the changes.** GitHub Pages rebuilds automatically.The homepage and Resource Library page will now show this as the newest file in the "Latest upload" button, and it'll appear in both the dropdown and the full table.## 3\. Before going fully live — two things to set up**A. Contact form (Formspree)**The form on `contact.html` is wired to send you an email, but needs your Formspree form ID before it'll work:1. Go to [formspree.io](https://formspree.io) and sign up free with `ancientadvancedindia@gmail.com`.2. Create a new form — Formspree gives you an endpoint like `https://formspree.io/f/abcd1234`.3. Open `contact.html`, find this line near the top of the form:```html   <form ... action="https://formspree.io/f/YOUR\\\\\\\_FORM\\\\\\\_ID" method="POST">   ```Replace `YOUR\\\\\\\_FORM\\\\\\\_ID` with the ID Formspree gave you.4. Commit and push. Submit the form once yourself from the live site — Formspree will email you a confirmation link the first time; click it to activate the form.5. Every submission after that arrives in your inbox with the subject **"AAI-Webform Inquiry"**, and replying goes straight back to whoever filled out the form.   **B.
